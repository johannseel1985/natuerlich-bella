# Live-Fassung natuerlichbella.de

Dieser Zweig enthält die fertige Website, so wie sie bei ALL-INKL liegt.
Jeder Push auf `live` lädt sie per FTPS hoch (`.github/workflows/hochladen.yml`).
Die Zugangsdaten liegen als verschlüsselte Repo-Geheimnisse `FTP_BENUTZER` und `FTP_PASSWORT`.
Der Zweig `main` bleibt die Vorschau auf GitHub Pages.
