# Natürlich Bella · Designvorschau

Statische Vorschau des Website-Entwurfs für Natürlich Bella Kosmetik in Lichtenau.

Vorschaulink: https://johannseel1985.github.io/natuerlich-bella/

## GitHub Pages

Unter Settings → Pages die Quelle „Deploy from a branch“, Branch `main` und Ordner `/(root)` wählen. Die Datei `.nojekyll` sorgt dafür, dass die fertigen HTML-Dateien unverändert bereitgestellt werden.

Die Vorschau enthält 11 Inhaltsseiten, zwei Weiterleitungsseiten und eine 404-Seite. Alle HTML-Seiten sind mit `noindex` versehen. Der Link ist öffentlich erreichbar und nicht passwortgeschützt.

Die Dateien sind für den Projektpfad `/natuerlich-bella/` vorbereitet. Bei einer späteren Bereitstellung unter einer eigenen Domain müssen die internen Pfade, Canonicals und Metadaten auf diese Domain angepasst werden.

## Funktionen

Responsive Navigation, Behandlungsfilter und vorbereitete E-Mail-Anfragen. Das Formular öffnet das E-Mail-Programm. Es gibt keine automatische Reservierung, kein Formular-Backend und keine Tracking-Skripte im Website-Code. Schriften und Bilder werden lokal ausgeliefert.
